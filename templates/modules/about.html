A computational model inspired by the human brain, used for structured/tabular data prediction.

Convolutional Neural Network (CNN)

Specialized for image data. Automatically learns spatial features like edges, textures, and shapes.

{% for title, icon, color, desc in [ ('Convolution Layer', 'fa-border-all', '#6f42c1', 'Applies learnable filters (kernels) across the image.
